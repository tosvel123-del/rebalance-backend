# ISA 프로젝트 문서

개발 기준은 [ISA 통합 개발계획서 1.0](ISA_DEVELOPMENT_PLAN_V1.0_20261109.md)이다. 투자전략, 포트폴리오 웹앱 기능, KIS 조회 연동 조건, 구현 우선순위와 검증 체크리스트를 통합했다.

- [통합 개발계획서 1.0](ISA_DEVELOPMENT_PLAN_V1.0_20261109.md) — 현재 개발 기준.

- [V2.3 원본 백업](backups/ISA_INVESTMENT_PLAN_V2.3_20261109.before-development-plan.md) — 통합 개발계획 추가 직전 원본과 동일한 내용.

## 핵심 기준

- 5개 ETF, 월 환산 40/70/100만 원, MMF 목표 25/20/15%.
- 화요일·목요일 주간 신규 예산의 50%씩, 10:30 우선·14:30 대안.
- 기본 현재가 10초, 상세 3~5초, 매수 화면 수동 갱신, 일봉 일 1회.
- 주문은 사용자가 한국투자증권 공식 앱에서 직접 실행. 주문 API 미구현.
- 공식 조회 전용 권한 확인 전 실전 App Key/Secret 연결 금지. 시세 조회도 예외 없음.
- 비밀정보는 채팅·소스·문서·로그에 보관하지 않음.

기존 V2.3의 미래 자동매수 설명은 연구 기록이다. 현재 개발 범위에 주문 기능을 추가하는 근거로 사용하지 않는다.
